# dop-learning-pipelines

Example CodePipeline and CodeBuild definitions for the three applications.

## Structure
- `task-tracker/` — SAM-based pipeline
- `inventory-service/` — CDK-based pipeline
- `status-dashboard/` — CloudFormation-based pipeline

These are skeletons you can deploy with CloudFormation or CDK and wire to GitHub (via CodeStar Connections).
